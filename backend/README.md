**Materia:** Programación Web II
**Descripción:** API REST desarrollada para la gestión de productos como parte del Primer Parcial Práctico.

## Tecnologías utilizadas
* Node.js
* Express
* Sequelize (ORM)
* SQL Server
* Postman (para pruebas)

## Instrucciones de Instalación y Ejecución

1. Clonar el repositorio.
2. Navegar a la carpeta `backend/`.
3. Instalar las dependencias con el comando:
   ```bash
   npm install
   ```
4. Configurar las variables de entorno. Duplica el archivo `.env.example`, renómbralo a `.env` y configura tus credenciales de SQL Server.
5. Iniciar el proyecto con el comando:
   ```bash
   node app.js
   ```
